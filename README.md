# OpenCart Selenium Python Automation Framework

## Description
This project is a professional QA Automation Framework developed using Python, Selenium, and Pytest. It automates end-to-end testing of the OpenCart e-commerce application using the Page Object Model (POM) design pattern and follows industry-standard automation practices.

## Tech Stack
- Python
- Selenium
- Pytest
- WebDriver Manager
- Git
- GitHub
- VS Code
